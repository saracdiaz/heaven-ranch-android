# Heaven Ranch para Android

APK oficiales de Heaven Ranch. El código fuente se mantiene en un repositorio privado.

## Instalar

Descarga la APK de la última publicación en Releases, ábrela en Android y confirma la instalación. Compatible con Android 8.0 o posterior; requiere Internet y abre la web de producción.

La app comprueba actualizaciones al arrancar. Si hay una versión nueva, ofrece descargarla. Android siempre pide confirmar su instalación. Las actualizaciones de la web se ven automáticamente.

Si instalaste la antigua APK de desarrollo 1.0.0, desinstálala una vez antes de instalar 1.1.0, que usa la firma estable de distribución. Las próximas versiones conservarán esa firma y podrán instalarse como actualizaciones.

No se incluyen PIN, sesiones, claves de Supabase ni claves privadas de firma.
